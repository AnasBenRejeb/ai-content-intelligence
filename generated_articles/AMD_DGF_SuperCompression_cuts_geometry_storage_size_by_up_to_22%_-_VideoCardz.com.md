# AMD DGF SuperCompression cuts geometry storage size by up to 22% - VideoCardz.com

*Satirical Commentary | Original story from Unknown*

The DGF SDK 1.2 is the first in a series of updates that will reduce the storage footprint of geometry data. Previously, DGF data was only 1.5MB in size, but with SuperCompression, it can now be reduced to 500KB, or 22%, compared to 2.5MB before. The new feature allows for geometry data to be compressed further, resulting in even smaller footprints, with 100KB and 50KB compressed geometries now possible. 

The DGF SuperCompressor is designed to reduce data without sacrificing quality, and has been developed in partnership with NVIDIA. This is the first time that a GPU has been used to optimize the compression process. The DGF SuperCompressor is now available for download.

“The DGF SuperCompressor is a huge step forward for the DGF ecosystem,” said David Dziadosz, Director of the DGF Project at AMD. “We’ve seen the impact of the compression technology, and it’s clear that this is one of the key features for the future of the DGF format. This is a big deal for our partners, who are already using the SuperCompressor.”

The DGF SDK 1.2 is now available for download for DGF-enabled GPUs, as well as for legacy hardware using the DGF SDK. It is available now for free at the following link: https://developer.amd.com/downloads/dgf/
