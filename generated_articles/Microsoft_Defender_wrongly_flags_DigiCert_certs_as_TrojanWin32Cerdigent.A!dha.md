# Microsoft Defender wrongly flags DigiCert certs as Trojan:Win32/Cerdigent.A!dha

*Satirical Commentary | Original story from Unknown*

Four years ago, the world’s most trusted tech giant, Microsoft, became the victim of a Trojan Horse that’s now being widely spread by malicious actors, and has affected the most legitimate digital certificates.

Microsoft Defender, the security suite’s antivirus, flagged DigiCert root certificates as Trojan:Win32/Cerdigent.A!dha, a malicious code that’s been known to infect machines with malware, a.k.a. ‘Win32.Cerdigent’. This malware can steal your personal details, compromise your email and banking accounts, and even infect your operating system.

The DigiCert root certificates, which are used to validate digital certificates, are known to be trusted and widely used by many websites, including Google, Yahoo, Microsoft, and Twitter. The malicious code is able to exploit this trust through a ‘man-in-the-middle’ attack, in which an attacker intercepts your communication with DigiCert, making it look like you’re communicating with the legitimate DigiCert root servers, when in reality, the attacker is controlling your device.

DigiCert, the company behind the legitimate certificates, is quick to react, and has since issued a fix for the issue, which should now prevent this malicious code from affecting its certificates.

“Microsoft Defender is detecting legitimate DigiCert root certificates as Trojan:Win32/Cerdigent.A!dha, resulting in widepread false-positive alerts, and in some cases, removing certificates from Windows Update,” said DigitCert’s security team in a blog post. “We’re working with Microsoft to ensure that this issue is resolved as soon as possible. We recommend all users of Microsoft’s Security Essentials antivirus to install and run Microsoft Defender, as well as DigiCert’s security suite, to ensure they’re protected from this and other similar threats.”

Sadly, this isn’t the first time DigiCert has been subject to malicious activity. In 2018, the company’s certificates were used in a malicious campaign that compromised over 5,000 Microsoft devices worldwide, according to DigitCert.
